# Online Retail Sales Analysis Dashboard using Excel

## Project Overview

This project focuses on analyzing online retail sales data and creating an interactive dashboard in Microsoft Excel. The dashboard provides valuable business insights related to customer behavior, sales trends, order performance, and regional sales distribution.

The project demonstrates skills in data cleaning, data processing, data visualization, and dashboard creation using Excel.

---

## Objectives

* Analyze annual online store sales performance
* Identify top-performing states and sales channels
* Understand customer purchasing behavior
* Compare sales and order trends by month
* Analyze gender-wise and age-group-wise sales
* Generate business insights for decision-making

---

## Dataset Information

The dataset contains e-commerce transaction details including:

* Order ID
* Customer ID
* Gender
* Age Group
* Sales Channel
* Product Category
* Order Status
* State and City
* Sales Amount
* Quantity
* Order Date

---

## Tools & Technologies Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Slicers
* Data Cleaning
* Dashboard Design
* Data Visualization

---

## Dashboard Features

* Top 5 Sales by State
* Sales by Age Group
* Monthly Sales vs Orders Analysis
* Gender-wise Sales Distribution
* Order Status Analysis
* Channel-wise Sales Analysis
* Interactive Filters using Slicers

---

## Key Insights

* Women customers contributed the highest percentage of sales.
* Maharashtra, Karnataka, and Uttar Pradesh generated the highest sales.
* Most orders were successfully delivered.
* Amazon, Myntra, and Flipkart were the top-performing sales channels.
* Adult customers aged 25–50 were the major customer segment.

---

## Business Recommendation

Target women customers aged 25–50 living in Maharashtra, Karnataka, and Uttar Pradesh through marketing campaigns on Amazon, Myntra, and Flipkart to improve sales performance.
